Edition 0.1 Archival Release

The archival-release specification for preserving the initial CSI Reference architecture as a fixed, independently verifiable scholarly object.

The website remains living documentation. The archival release will preserve an immutable snapshot of Edition 0.1, its governance records, source registry, citation metadata, licensing terms, and file-integrity evidence.

Integrity and reproducibility

The repository contains a release-build script that copies the approved files into a versioned package, records their canonical URLs and versions, computes SHA-256 checksums, and generates a machine-readable manifest. Checksums must be generated from the exact tagged release commit rather than estimated in advance.

License

Except where otherwise noted, original CSI Reference scholarly text, diagrams, and archival-release materials are licensed under Creative Commons Attribution-NonCommercial 4.0 International. Third-party material, trademarks, branding, and repository code remain outside that license unless expressly stated.

Identifiers and Zenodo pathway

The release package is prepared for publication as a tagged GitHub Release and archival ingestion through Zenodo. The repository includes Zenodo-specific metadata in .zenodo.json and citation metadata in CITATION.cff. A DOI has not yet been assigned. Once Zenodo publishes the record, the assigned DOI should be added to the living site, article metadata, citation exports, and release manifest through a new version-controlled update.

Research status

Archiving establishes persistence and citability; it does not constitute peer review, empirical validation, or journal acceptance. Edition 0.1 remains a foundational conceptual release aligned with the current pre-submission theoretical manuscript.

Repository package

The prepared package specification is maintained under archive/edition-0.1/. The build command is python scripts/build_release_archive.py. The resulting manifest records 22 checksummed release files for deposit.
