# TDR-003 — Distinguish Observation, Evidence, Indicator, Construct, and Estimate

**Status:** Accepted

## Decision

CSI shall treat observations, evidence, indicators, constructs, and estimates as distinct conceptual entities.

## Scientific Rationale

A recorded event does not acquire construct meaning automatically. Observations become evidence relative to an inferential claim; evidence becomes an indicator only when theory or accumulated empirical support links it to a construct; the construct remains distinct from the computational estimate produced about it.

This separation is necessary to prevent category errors such as equating feature importance with construct validity or treating a model output as the latent state itself.

## Alternatives Considered

### Use observation, evidence, and indicator interchangeably

Rejected because this obscures the theoretical steps through which raw data support scientific interpretation.

### Treat the model estimate as the construct

Rejected because the estimate is an inferential claim about the latent construct, not the construct itself.

## Consequences

CSI documentation and future papers should preserve these distinctions explicitly in operationalization, model specification, and validation.

## Backward Compatibility

Backward compatible. The decision clarifies the epistemic structure already implicit in CSI.
