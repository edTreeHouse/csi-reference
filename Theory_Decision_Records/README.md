# CSI Theory Decision Records

Theory Decision Records (TDRs) document significant conceptual decisions affecting the Collective-State Inference framework.

Each TDR should record:

- TDR number
- title
- status: Proposed, Accepted, Deferred, Superseded
- date
- decision
- scientific rationale
- alternatives considered
- consequences
- backward compatibility
- related Theory Handbook sections
- related research papers
